## 🚀 About the Project

Welcome to **Principles of Data Science - Group 2**! This project focuses on analyzing a dataset using various phases of a data analysis workflow. Our work includes individual research contributions and a final **time series analysis** with forecasting.

### 📌 Key Features:

The `product_time_series_analysis.ipynb` notebook contains:
- Data preprocessing and cleaning steps.
- Exploratory data analysis (EDA).
- Data clustering
- Time series analysis and forecasting using appropriate models.
- Final insights and conclusions.

### 📂 Project Structure:
- **`data/`** - Contains the dataset used for analysis.
- **`Dhanushi/ Shalindri / Suneth / Suraj/`** - Individual research contributions.
- **`product_time_series_analysis.ipynb`** - Finalized analysis including forecasting.


   ```bash

   ```
4. Open and explore the Jupyter Notebook:
   ```bash

   ```
